# Paths

The four Paths remain:

```text
Scribe
Channeler
Artificer
Null
```

Path mechanics are an extension of character development and do not replace existing Glyphic Resonance rules.

## Scribe

Favored skills:

```text
Glyphcraft
Scholarship
Resonance
Investigation
```

Development emphasizes preparation, inscription, structure, and control.

## Channeler

Favored skills:

```text
Melee
Athletics
Fortitude
Resolve
```

Development emphasizes physical Resonance expression and controlled overchanneling.

## Artificer

Favored skills:

```text
Engineering
Sleight
Investigation
Glyphcraft
```

Development emphasizes devices, preparation, adaptation, and field repair.

## Null

Favored skills:

```text
Resonance
Awareness
Resolve
Fortitude
```

Development emphasizes disruption, suppression, resistance, and denial.

## Path Training

Choosing a Path grants:

```text
2 Path Skill Trainings
1 Path Ability
```

If a Path Skill is already Trained, duplicate training may raise it to Skilled.

Path abilities are defined separately in `Path-Abilities.md`.
