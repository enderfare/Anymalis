# Description
This rule defines the six core attributes, resonance statistics, and derived values used in Glyphic Resonance. All characters follow this framework regardless of their path (Scribe, Channeler, Artificer, Null).

# Core Concept
Power is not determined solely by magical ability. There are four equally viable paths, each interacting with Resonance differently. The statistics reflect both mundane and magical aptitudes.

# The Six Attributes
- **Might (MGT):** physical strength, melee damage.
- **Finesse (FIN):** agility, reflexes, precision.
- **Endurance (END):** health, stamina, resilience.
- **Intellect (INT):** knowledge, glyph comprehension, engineering.
- **Insight (INS):** perception, resonance sensitivity.
- **Presence (PRS):** willpower, charisma, mental stability.

# Point Buy Generation
- Base: 8 in all attributes.
- 72 points to distribute.
- Maximum starting stat: 18.
- **Soft Cap:** After 16, each point costs double.

# Universal Resonance Statistics
## Resonance Capacity (RES)
`[Insight × 2] + [Presence] + Training`
Determines magical awareness, enchanted item use, resistance to disruption, and anti‑magic interaction.

## Sanity (SAN)
`[Insight × 5] + [Intellect + Presence]`
Mental stability against resonance corruption. Threshold effects range from clarity (+2 Insight at 90‑100%) to mental collapse (0‑9%).

## Energy (ENR)
`[Endurance × 4] + [Might × 2]`
Physical stamina pool. Used for sprinting, martial techniques, and Channeler abilities.

## Animent (ANI)
`[Insight × 3] + [Presence × 2] + Element Tier Bonus`
Raw magical energy. Only usable by Scribes and certain Artificers. Tier bonuses: Mythic +30, Primordial +25, Fundamental +20, Physical +15, Terrestrial +10.

## Glyphic Ink Capacity (INK)
`1 + [Intellect ÷ 4] + Affinity Bonus`
Maximum prepared or active glyph structures. Affinity bonus follows tier.

## Strain (STRN)
`[Endurance × 2] + [Presence]`
Used by Channelers to force resonance through the body. Strain thresholds cause fatigue, pain, internal damage, and physical collapse.

# Biological Statistics
## Animal Trait Score (ATS)
d10 scale (0‑10). Each tier grants +2 to one physical stat and -1 to one mental stat, plus enhanced senses/natural weapons.
## Hybrid Trait Score (HTS)
d10 scale (0‑10). Represents mixed‑species lineage.
## Quimera Percentage (Q%)
`[ATS × 5] + [HTS × 3] + [RES ÷ 10]` — likelihood of unstable offspring.

# Derived Statistics
- **HP:** `[Endurance × 3] + [Adventuring Tier × 2]`
- **Defense:** `10 + Finesse Modifier + Armor + Shield`
- **Initiative:** `d20 + Finesse Modifier + Insight Modifier`
- **Carry Capacity:** `Might × 15 lbs`
- **Speed:** `30 ft + [Finesse Modifier × 5]`
- **Glyph Save DC:** `8 + INT Modifier + INS Modifier + Proficiency`
- **Glyph Attack:** `INT or INS Modifier + Proficiency`
- **Magical Resistance:** `Insight Score + Wards + RES Modifier`
- **Resonance Resistance:** `Presence Modifier + RES ÷ 2`

# The Four Resonance Paths
Outlined in the main rules; each path uses different resource pools:
- **Scribes:** ANI, INK, SAN.
- **Channelers:** ENR, STRN.
- **Artificers:** tools, cartridges, devices.
- **Nulls:** anti‑resonance, immunity.

# Progression System
No traditional levels. Growth through training (months to years for attributes/skills), glyph study, resonance exposure (mutation, scars), and transformative events.

# Combat Philosophy
Magic is slow, material‑dependent, and interruptible. Martial pressure counters casters; preparation and control win fights.

# Environmental Resonance
Locations alter magic: Dead Zones weaken, Overflow Regions make spells stronger but unstable, Ancient Glyph Fields react unpredictably, Hollow Storms cause SAN damage.

# Interaction with Mythic Meta‑Glyphs
When dealing with Prima or Nihil, Resonance Stability (RST) becomes critical: `[Insight + Endurance + Training]`. Overflow occurs when resonance output exceeds RST, leading to reality distortion.
