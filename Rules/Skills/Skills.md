# Skills

There are 18 universal skills.

## Might

| Skill | Uses |
|---|---|
| Athletics | Climbing, jumping, swimming, physical traversal |
| Melee | Close combat and weapon handling |
| Force | Grappling, shoving, breaking, overpowering |

## Finesse

| Skill | Uses |
|---|---|
| Acrobatics | Balance, tumbling, evasive movement |
| Marksmanship | Bows, thrown weapons, precision attacks |
| Sleight | Fine manipulation, theft, delicate work |

## Endurance

| Skill | Uses |
|---|---|
| Fortitude | Pain, poison, injury, exhaustion |
| Survival | Wilderness travel and fieldcraft |
| Recovery | Stabilization and functioning while injured |

## Intellect

| Skill | Uses |
|---|---|
| Scholarship | History, science, languages, culture |
| Engineering | Machines, structures, tools, repair |
| Glyphcraft | Understanding existing Glyph structures |

## Insight

| Skill | Uses |
|---|---|
| Awareness | Immediate perception and danger detection |
| Resonance | Detecting and interpreting Resonance |
| Investigation | Evidence, deduction, reconstruction |

## Presence

| Skill | Uses |
|---|---|
| Influence | Persuasion, negotiation, leadership |
| Deception | Lying, disguise, misdirection |
| Resolve | Mental endurance, composure, determination |
