# Traits

Traits are persistent qualities.

A Trait answers:

> What is permanently true about this character?

Examples:

```text
Ambidextrous
Acute Hearing
Iron Will
Night Adaptation
Photographic Memory
Resonance Sensitive
Natural Climber
Unusual Anatomy
```

Traits can come from:

- Backgrounds.
- Lineages.
- Paths.
- Training.
- Transformations.
- Major story events.

Traits should have a concrete mechanical or narrative effect.

Avoid using Traits as generic +1 bonuses when a more specific rule is possible.
