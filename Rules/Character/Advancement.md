# Advancement

Anymalis does not use traditional character levels or XP.

Advancement happens through meaningful development.

```text
Practice
Instruction
Experience
Mastery
Transformation
```

## Skill Mastery

| Rank | Name | Bonus |
|---:|---|---:|
| 0 | Untrained | +0 |
| 1 | Trained | +2 |
| 2 | Skilled | +4 |
| 3 | Expert | +6 |
| 4 | Master | +8 |
| 5 | Legendary | +10 |

## Advancement Table

| From | To | Requirement |
|---|---|---|
| Untrained | Trained | Meaningful practice |
| Trained | Skilled | Significant practice + successful application |
| Skilled | Expert | Advanced instruction + specialized experience |
| Expert | Master | Long-term mastery + Mastery Trial |
| Master | Legendary | Transformative achievement + Legendary Deed |

## Mastery Proofs

### Trained

The character has spent meaningful time learning the skill.

### Skilled

The character has demonstrated practical competence under pressure.

### Expert

The character has advanced instruction or equivalent professional experience.

### Master

The character completes a meaningful Mastery Trial.

Examples:

```text
Repair an ancient Resonance engine during catastrophic failure.
Defeat a master swordsman using a chosen discipline.
Lead an expedition through an unstable Resonance region.
Reconstruct a historical event from fragmented evidence.
```

### Legendary

The character completes a deed that establishes lasting reputation or transforms their understanding of the skill.

Legendary advancement should be rare.

## Attribute Advancement

Attributes advance more slowly.

Normal maximum:

```text
20
```

Exceptional development may reach:

```text
22
```

Extraordinary transformation may permit:

```text
24
```

Higher values require explicit campaign-level justification.
