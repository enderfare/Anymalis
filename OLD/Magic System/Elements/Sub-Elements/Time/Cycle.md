# Description
Cycle is the loop, the echo, the recurrence. Masters can trap enemies in endless moments or create spells that renew themselves.

# Affinity Effects
- **Passive:** You have advantage on Insight checks to detect deception.
- **Active:** Once per long rest, you can force an enemy to repeat its last action.
- **Intuitive Understanding:** You can recall with perfect clarity any event you’ve witnessed in the past week.
