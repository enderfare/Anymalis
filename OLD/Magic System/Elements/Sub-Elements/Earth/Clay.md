# Description
Clay is the artist’s earth. It is moldable, shapeable, and holds the memory of every form pressed into it.

# Affinity Effects
- **Passive:** You may create a small, crude clay figurine that can deliver touch spells once before crumbling.
- **Active:** Once per long rest, you can animate a human‑sized clay statue for 1 hour (use stats of an animated armor).
- **Intuitive Understanding:** You can read the fingerprints of anyone who handled a clay object in the past week.
