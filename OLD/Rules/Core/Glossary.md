# Anymalis Glossary

| Term | Definition |
|---|---|
| **Anymalis** | The system through which the world's magical phenomena are structured and understood. |
| **Elemental Resonance** | The magical phenomenon of elemental currents interacting with reality. |
| **Element** | A fundamental magical principle. |
| **Variant** | A specific expression of exactly one Element. |
| **Glyph** | A structured symbol or construction used to shape Elemental Resonance. |
| **Core Glyph** | The part of a Glyph construction that establishes its Element. |
| **Border** | A construction component that modifies how Elemental Resonance behaves. |
| **Foundation** | A Border that increases the conceptual importance of an existing Glyph. |
| **Spell** | A complete magical construction and its resulting effect. |
| **Ink** | A conductive material traditionally used to construct Glyphs. |
| **Animen** | A personal magical resource that can allow direct construction without conventional Ink. |
| **Resonant Thread** | The Sericari's specialized method of conducting and constructing Glyphs. |
| **Surface** | The physical medium on which or through which a Glyph is manifested. |
| **Resonant Surface** | A Surface explicitly defined as providing an additional magical or mechanical effect. |
| **Resonant Scar** | The natural glyph-like mark associated with a character's innate magical resonance. |
| **Elemental Affinity** | A character's natural compatibility with an Element and Variant. |
| **SAN** | Mental and psychological stability; all characters possess SAN. |
| **Glyph Fatigue** | Physical and metaphysical strain associated with manipulating Elemental Resonance through a naturally magical body. |
| **Path** | A character's primary specialization in interacting with Elemental Resonance. |
| **Scribe** | A Path specialized in Glyph design and construction. |
| **Channeler** | A Path specialized in channeling Elemental Resonance through the body. |
| **Artificer** | A Path specialized in creating tools and devices that use Glyphs. |
| **Null** | A Path and broader category associated with absent, damaged, suppressed, or severed Resonant signatures. |
| **Prima** | A Meta-Glyph associated with creation and the establishment of new relationships or possibilities. |
| **Nihil** | A Meta-Glyph associated with cancellation, denial, and the removal of definition or continuity. |
