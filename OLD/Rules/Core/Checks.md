# Checks

The universal skill check is:

```text
d20
+ Attribute Modifier
+ Skill Mastery Bonus
+ Specialization Bonus
+ Situational Modifiers
```

## Difficulty

| DC | Difficulty |
|---:|---|
| 5 | Trivial |
| 10 | Easy |
| 15 | Moderate |
| 20 | Hard |
| 25 | Very Hard |
| 30 | Extreme |
| 35 | Legendary |

## Flexible Attributes

A skill has a default attribute, but the GM may substitute another attribute when the character approaches the problem differently.

Example:

```text
MGT + Athletics
```

may represent forcing yourself up a wall.

```text
FIN + Athletics
```

may represent climbing with precise movement.

The skill describes the learned capability.
The attribute describes the approach.
