# Specializations

A Specialization is a focused application of a Skill.

A relevant Specialization grants:

```text
+2
```

## Examples

```text
Engineering
├── Machinery
├── Architecture
├── Resonance Devices
└── Improvisation

Investigation
├── Forensics
├── Archaeology
├── Social Deduction
└── Pattern Analysis

Melee
├── Blades
├── Polearms
├── Unarmed
└── Improvised Weapons

Scholarship
├── History
├── Biology
├── Politics
└── Resonance Theory
```

Specializations do not create new skills.

## Acquisition

| Skill Rank | Specialization |
|---|---:|
| Trained | 0 |
| Skilled | 1 |
| Expert | 2 |
| Master | 2 + Master Specialty |
| Legendary | Legendary Domain |

### Master Specialty

Choose one existing Specialization.

It gains an additional:

```text
+2
```

when directly relevant.

### Legendary Domain

A narrow field within an existing specialization.

The primary benefit is expanded permission: the character may attempt actions beyond ordinary capability.
