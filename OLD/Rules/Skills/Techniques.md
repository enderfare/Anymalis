# Techniques

Techniques are learned actions, methods, or maneuvers.

They are not Glyphs and do not alter Glyphic Resonance.

A Technique should define:

- Action type.
- Requirements.
- Target.
- Effect.
- Resource cost, if any.
- Restrictions.
- Consequences.

## Technique Grades

| Grade | Minimum Skill Rank |
|---|---|
| Basic | Trained |
| Advanced | Skilled |
| Expert | Expert |
| Master | Master |
| Legendary | Legendary |

## Starting Techniques

Every character begins with:

```text
2 Basic Techniques
```

Additional techniques may come from:

- Skilled mastery.
- Expert mastery.
- Master mastery.
- Legendary mastery.
- Lineages.
- Paths.
- Backgrounds.
- Major story achievements.

## Technique Capacity

| Stage | Gain |
|---|---:|
| Creation | 2 Basic |
| Skilled | +1 |
| Expert | +1 |
| Master | +2 |
| Legendary | +1 Legendary |

Techniques may use existing resources such as ENR or STRN. They should not create a parallel universal magic resource.
