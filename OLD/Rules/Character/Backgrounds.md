# Backgrounds

A Background represents the character's life before the campaign.

Examples:

```text
Archivist
Courier
Craftsman
Explorer
Field Researcher
Hunter
Medic
Mercenary
Relic Hunter
Scholar
Performer
Criminal
```

## Background Package

Every Background grants:

```text
2 Skill Trainings
1 Specialization
1 Background Trait
```

If a Background grants a Skill already Trained, the duplicate may instead raise that Skill to Skilled.

Backgrounds should establish identity and history without becoming another class system.
