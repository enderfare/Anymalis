# Signature Spell

## Frozen Verse

**Element:** Time — Still

**Ink:** Silverthread

**Surface:** Cathedral glass

**Borders:**
- Anchor
- Duration
- Precision
- Echo

### Effect

For seven seconds, everything inside the Glyph slows nearly to a halt.

Sound distorts.

Rain freezes.

Flames stop.

Only Seraphine moves normally.

When the effect ends, stored momentum returns simultaneously.

### Limitations

- Requires prepared Glyphwork.
- High cognitive strain.
- Repeated use causes memory degradation.
- Strong emotional disruption may destabilize the borders.
