# Description
Still is the moment between heartbeats. It freezes, preserves, and isolates.

# Affinity Effects
- **Passive:** Objects you hold can be locked in stasis, preventing decay.
- **Active:** Once per long rest, you can freeze a single creature in time for 1 round.
- **Intuitive Understanding:** You know the exact age of anything you touch.
