# Description
Void is the annihilation of presence. It erases, denies, and unmakes temporary realities. Users walk in silence and are often feared.

# Affinity Effects
- **Passive:** Enemies within 10 ft suffer disadvantage on Perception checks relying on sight or hearing.
- **Active:** Once per long rest, you can create a zone of absolute silence and darkness for 1 minute.
- **Intuitive Understanding:** You know if a creature has experienced memory loss or tampering.
