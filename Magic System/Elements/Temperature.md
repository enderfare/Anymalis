# Description
Temperature masters regulate heat and cold, never directly creating flame or ice but shifting the environment. They are essential in climates where survival depends on thermal control.

# Manifestation
Glyphs shimmer with heat haze or frost; the air around them crackles with static.

# Variants
| Variant | Description |
|---------|-------------|
| [[Heat]] | Raising temperature, inducing warmth. |
| [[Cold]] | Lowering temperature, freezing. |
| [[Equilibrium]] | Perfect stability, neutralizing extremes. |
| [[Conduction]] | Transferring heat rapidly. |
| [[Insulation]] | Blocking thermal transfer. |
| [[Phase‑Change]] | Triggering melting, boiling, condensation. |

# Cultural Significance
- **Common Roles:** Survival experts, chefs, smiths (assisting forge work), explorers.
- **Special Rules:** Temperature glyphs cannot create matter—they only alter existing thermal energy.

# Sample Birthmark Appearance
A thermally sensitive mark that feels warm or cool depending on the caster’s mood.
