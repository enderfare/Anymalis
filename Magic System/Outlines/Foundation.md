# Foundation Outline

The Foundation outline is not optional — it is the **first ring** around any glyph, defining which element (and variant) the spell channels. Without it, resonance has no form and dissipates.

## Mechanical Effect
- **Identity Lock:** The glyph's element and variant are fixed; no other outline can change them.
- **Resonance Signature:** The glyph's aura is clearly visible to any resonance‑sensitive creature.
- **Casting Requirement:** All glyphs must include at least a Foundation outline, even if drawn instinctively.

## Common Interactions
- If a Foundation outline is damaged, the entire glyph unravels.
- Used with Anchor to create permanent elemental wards.
- Foundation + Echo + Transformation allows a spell to shift element over time (dangerous, requires RST check).

## Example Spell
**Elemental Ward** — Foundation (Earth‑Stone) + Containment + Duration. Creates a protective stone dome.
