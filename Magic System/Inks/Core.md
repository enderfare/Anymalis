# Resonance Inks

Ink is not merely a pigment; it is the **conductive medium** that allows a glyph to channel Resonance. Every ink is a recipe — a mixture of powdered metals, rare fluids, and alchemical reagents. The composition directly affects the spell's behaviour, power, stability, and cost.

## Ink Types
| Ink | Key Trait | Typical Element/Border Pairing |
|-----|-----------|-------------------------------|
| [[Silverthread]] | Precision, stability | Time, Light, Precision borders |
| [[Ember Ash]] | Explosive amplification | Fire, Fracture, Amplification |
| [[Verdant Sap]] | Regeneration, long duration | Life, Growth, Duration |
| [[Hollow Ink]] | Silence, concealment | Darkness, Veil, Null magic |
| [[Glasswater]] | Refraction, echo | Water, Illusion, Echo |

## How Ink is Obtained
- **Silverthread** — alchemists refine moonwater and silver dust.
- **Ember Ash** — harvested from volcanic ruins by Fire‑affinity mages.
- **Verdant Sap** — bled from ancient resonance‑trees by Verdant Sericari.
- **Hollow Ink** — extracted from void fungus in dead resonance zones.
- **Glasswater** — crystallised rainwater filtered through prism sand.

Mixing inks is possible but dangerous; uncontrolled blends may explode, curse the surface, or create unpredictable resonance feedback.
